# 🎯 랜덤 문제 마스터 (Random Problem Study Utility)

책에 있는 모르는 문제 번호들을 입력해 두고, 모든 문제를 완벽히 풀 수 있을 때까지 **랜덤 추첨 + 오답 반복** 방식으로 연습하는 개인 학습용 웹앱입니다.

별도의 빌드 과정이나 서버 없이 순수 HTML/CSS/JS로 제작되어 **GitHub Pages**에 바로 올려 사용할 수 있습니다.

---

## ✨ 주요 기능

1. **줄바꿈 기반 문제 목록 입력 (`<textarea>`)**
   - 환경설정에서 연습할 문제 번호를 한 줄에 하나씩 입력합니다 (`3`, `15`, `p.42 5번` 등 자유 형식 지원).
   - `1~20` 처럼 물결표로 범위를 적거나 **연속 번호 빠른 추가 도우미**를 사용하면 여러 번호를 한 번에 입력할 수 있습니다.
2. **3, 2, 1 카운트다운 애니메이션**
   - 문제를 뽑을 때 원형 게이지 및 팝 애니메이션, 효과음(켜기/끄기 가능)과 함께 3, 2, 1 카운트다운 후 번호가 출력됩니다.
   - 카운트다운 속도 조절(기본 / 빠르게 / 초고속) 및 즉시 건너뛰기를 지원합니다.
3. **[정답] / [오답] 판정 및 스마트 출제 후보 관리**
   - **⭕ [정답] 클릭**: 해당 번호는 해결 완료 처리되어 다음 랜덤 출제 후보에서 제외됩니다.
   - **❌ [오답] 클릭**: 다음 출제 후보에 그대로 유지되며, 문제별 **누적 오답 횟수**가 기록됩니다.
   - 남은 문제가 2개 이상일 때는 방금 풀었던 문제가 연속으로 다시 나오지 않도록 방지합니다.
4. **실시간 진행률 표시 (`정답처리한 갯수 / 총갯수`)**
   - 하단에 `정답처리한 갯수 / 총갯수 (진행률 %)`와 프로그레스 바, 남은 문제 수, 누적 오답 횟수가 표시됩니다.
5. **환경설정 & 초기화**
   - **진행도만 초기화**: 입력된 문제 목록은 유지한 채 `0 / 총갯수` 상태로 처음부터 다시 시작합니다.
   - **목록·진행도 모두 초기화**: 문제 목록과 기록을 완전히 비웁니다.
6. **추가 학습 편의 기능**
   - **브라우저 자동 저장 (`localStorage`)**: 새로고침하거나 창을 닫았다가 다시 열어도 학습 진행 상황과 목록이 그대로 유지됩니다.
   - **문제집 보관함 (프리셋)**: 단원별/책별로 문제 목록을 저장해 두고 언제든 불러올 수 있습니다.
   - **풀이 타이머 (스톱워치)**: 문제가 출력된 순간부터 풀이 시간을 자동으로 측정합니다.
   - **실행 취소 (`Undo`)**: 실수로 정답/오답을 잘못 눌렀을 때 바로 직전 상태로 되돌릴 수 있습니다.
   - **틀렸던 문제만 다시 풀기**: 모든 문제를 다 푼 뒤, 한 번이라도 오답을 눌렀던 취약 문제들만 추려서 재복습할 수 있습니다.
   - **키보드 단축키**: `Space`(문제 뽑기/건너뛰기), `O` 또는 `1`(정답), `X` 또는 `2`(오답), `Z`(실행 취소)

---

## 🚀 GitHub Pages 배포 방법

1. GitHub에 새 저장소(Repository)를 생성합니다.
2. 이 폴더의 `index.html`, `style.css`, `app.js`, `README.md` 파일을 푸시합니다.
3. 저장소의 **Settings → Pages** 메뉴로 이동합니다.
4. **Build and deployment**의 Branch를 `main` (또는 `master`) / `/(root)`로 선택하고 **Save**를 누르면 배포가 완료됩니다.
